# Оно тебе надо

Учебный проект, выполненный в рамках курса «Фронтенд-разработчик» Яндекс Практикума.

## Описание проекта

«Оно тебе надо» — одностраничный сайт аукциона необычных вещей. Проект посвящён отработке навыков семантической HTML-разметки, работе с Flexbox и Grid Layout, организации структуры страницы по методологии БЭМ и Pixel Perfect-вёрстке по макету Figma.

В проекте реализованы:

- шапка сайта с навигацией и контактной информацией;
- обложка с фоновым изображением и оверлеем;
- секция лотов с карточками аукциона;
- блок «Об аукционе»;
- подвал сайта с навигацией и ссылками на социальные сети.

## Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid Layout
- БЭМ (Nested)
- Семантическая вёрстка
- Pixel Perfect

## Планы по доработке

- Улучшение доступности интерфейса;
- Дополнительная адаптация под различные размеры экранов;
- Оптимизация структуры и переиспользования стилей.
